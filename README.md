# 🌿 Sustainability - SustainoScan AI

An intelligent waste classification system that uses AI to identify waste, provide disposal guidance, and promote sustainable practices.

## 📱 Project Overview

**SustainoScan AI** is a web-based application designed for the Science Sustainova 2026 competition. It leverages Google's Gemini AI to analyze images of waste and objects, providing real-time insights on:
- Waste classification and categorization
- Proper disposal methods using color-coded dustbin system
- Nature-friendly alternatives and benefits
- Interactive AI chat for additional guidance
- History tracking of scanned items

## ✨ Key Features

### 🎥 **Smart Waste Scanning**
- Real-time camera capture with live scanning animation
- File upload support for batch analysis
- Clear, instant waste identification

### 🤖 **AI-Powered Analysis**
- Detects waste objects and categorizes them
- Identifies nature-friendly items with health benefits
- Provides specific disposal recommendations
- Uses Google's Gemini 2.5 Flash for high-accuracy analysis

### 🗑️ **Bin Classification System**
- **Blue Bin**: Dry & Recyclable Waste (Sookha kachra)
- **Green Bin**: Wet & Compostable Waste (Geela kachra)
- **Red/Black Bin**: Hazardous Waste (Khatarnak kachra)
- **E-Waste**: Electronic waste special disposal instructions

### 💡 **Multiple Tips & Guides**
- **Kids Fun DIY**: Age 5-10 creative reuse ideas
- **Gen-Z Aesthetic**: Trendy sustainable hacks
- **Eco-Disposal**: Scientific disposal methods

### 💬 **Interactive AI Chat**
- Ask questions about detected items
- Get contextual sustainability advice
- Hinglish language support for accessibility

### 📜 **Scan History**
- Save and revisit previous scans
- Track chat conversations per session
- Easy session management

### 🔊 **Audio Feature**
- Text-to-speech result narration
- Accessibility support

## 🛠️ Tech Stack

- **Frontend**: React 18 (via CDN)
- **Styling**: Tailwind CSS
- **AI Engine**: Google Generative AI (Gemini 2.5 Flash)
- **Language**: JSX with Babel transpilation
- **Icons**: Custom SVG components
- **Storage**: Browser localStorage for session history

## 📋 Requirements

- HTTPS enabled website (for camera access)
- Google Gemini API key
- Modern browser with:
  - Camera/Media access permission
  - JavaScript enabled
  - Geolocation (optional)

## 🚀 How to Use

1. **Open the App**: Load `SustainoScan.html` in a browser (HTTPS required)
2. **Allow Camera Access**: Grant permission when prompted
3. **Capture Image**: Click "Scan" to capture via camera or "File" to upload
4. **View Analysis**: Get instant waste classification and disposal advice
5. **Explore Tips**: Expand tip sections for detailed sustainability guidance
6. **Chat with AI**: Ask follow-up questions about the detected item
7. **Review History**: Click "History" button to revisit previous scans

## 🌍 Impact & Mission

SustainoScan AI aims to:
- ♻️ Educate users on proper waste segregation
- 🌱 Promote sustainable living practices
- 👨‍👩‍👧‍👦 Make sustainability accessible to all ages (especially kids)
- 🔬 Leverage AI for environmental awareness
